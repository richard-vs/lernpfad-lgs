# Systems of Equations · Math Workshop

Responsive, interactive learning website for students in grades 8–10 to practise substitution, equating, and addition methods for solving systems of linear equations.

## Progress transfer

Use **Export progress** to download a JSON file to your device. Use **Import progress** to load it on another device. After confirmation, the imported progress replaces the progress saved there. The file stays with the learner; progress is not sent to a server.

## Publish with GitHub Pages

This is a static website. In the repository settings under **Pages**, select the `main` branch and the `/(root)` folder as the source. The home page is `index.html`.
