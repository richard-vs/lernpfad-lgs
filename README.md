# Lernpfad LGS

Interaktive Lernseite zu Lösungsverfahren für lineare Gleichungssysteme: Einsetzungs-, Gleichsetzungs- und Additionsverfahren.

## Lernstand übertragen

Mit **Lernstand exportieren** wird eine JSON-Datei auf das eigene Gerät heruntergeladen. Auf einem anderen Gerät kann sie über **Lernstand importieren** wieder eingelesen werden. Der importierte Stand ersetzt nach einer Bestätigung den dort gespeicherten Stand. Die Datei bleibt bei der lernenden Person; es werden keine Lernstände an einen Server übertragen.

## Veröffentlichung mit GitHub Pages

Die Website ist eine statische Seite. In den Repository-Einstellungen unter **Pages** kann als Quelle der Branch `main` und der Ordner `/(root)` ausgewählt werden. Die Startseite liegt in `index.html`.
