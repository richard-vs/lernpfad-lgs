# Lernpfad LGS

Interaktive Lernseite zu Lösungsverfahren für lineare Gleichungssysteme: Einsetzungs-, Gleichsetzungs- und Additionsverfahren.

## Veröffentlichung mit GitHub Pages

Die Website ist eine statische Seite. In den Repository-Einstellungen unter **Pages** kann als Quelle der Branch `main` und der Ordner `/(root)` ausgewählt werden. Die Startseite liegt in `index.html`.
